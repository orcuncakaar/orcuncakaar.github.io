# Odak logo seti

Kişisel sayfa: lacivert (`#152033`), merkezde nokta. Blog/yazılar: petrol yeşili (`#087d89`), merkezde iki yazı çizgisi. Her ikisi ilk **Odak** önizlemesinin geometrisini kullanır.

- `odak-personal.svg`, `odak-blog.svg`: yuvarlatılmış kare içinde ana simgeler; vektör kaynak.
- `*-mark.svg`: şeffaf zemin üzerinde lacivert işaret.
- `*-mark-white.svg`: koyu zemin için şeffaf, beyaz işaret.
- `*-16.png`, `*-32.png`, `*.ico`: tarayıcı sekmesi.
- `*-180.png`: Apple dokunmatik simgesi.
- `*-192.png`, `*-512.png`: uygulama simgesi.
- `*-maskable.svg`, `*-maskable-512.png`: tam dolu kare zemin; ana işaret merkezdeki güvenli dairenin içinde kalır, cihaz kendi maskesini uygular.

PNG dosyaları SVG kaynağın ilgili piksel boyutunda rasterleştirilmiş karşılıklarıdır. ICO 16, 32 ve 48 piksel içerir. Yeni bir tasarımda önce SVG kaynaklarını, ardından raster karşılıklarını birlikte güncelleyin.
